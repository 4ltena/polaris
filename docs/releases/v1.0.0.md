# Polaris 暫定v1.0.0 — macOS TUI

Polaris暫定v1.0.0は、macOS arm64のTUIを配布対象とする版である。現在は公開準備中であり、タグ・GitHub Release・download URLはまだ公開していない。GUIと他OSのソースは保持するが、今回の配布物には含めない。

## 導入するもの

CLI/TUI実行物だけを含む`polaris-cli-preview-1.0.0-arm64.pkg`を用意する。モデルweights、llama.cpp、Python、Rust、GUI、個人設定・認証情報は含めない。利用者側のRustは不要で、主モデル用の認証またはlocal endpointを別途設定する。

パッケージは未署名・未公証のローカル候補である。Gatekeeperの警告を無視する手順は提供しない。公開用署名や公証を済ませた配布物とは区別する。

2026-10-26に照合した候補は次のとおり。公開download URLはまだない。署名や再生成の後はSHA-256を確定し直す。

| ファイル | 対象 | サイズ | SHA-256 |
| --- | --- | ---: | --- |
| `polaris-cli-preview-1.0.0-arm64.pkg` | macOS arm64 CLI/TUI | 21,861,920 bytes | `7e87c65d1af2e97d6f44c575432bb52cc233f4ca9c366b9aa0dcd8fff7e07ef2` |

```sh
# 公開後、取得したファイルのSHA-256を配布元の値と照合する
shasum -a 256 polaris-cli-preview-1.0.0-arm64.pkg
# 管理者が導入を承認した場合だけ実行する
sudo installer -pkg polaris-cli-preview-1.0.0-arm64.pkg -target /
polaris --version
polaris login
cd /path/to/project
POLARIS_PROVIDER=codex polaris
```

導入先は`/usr/local/bin/polaris`。異なる既存コマンドやsymlinkを検出するとpreinstallが拒否する。既存ファイルの削除・置換をこの手順で自動化しない。別のPATH上に開発用コマンドがある場合は、`command -v polaris`で起動先を確認する。

## 追加・変更・修正

### 対話と認証

- TUIの既定・推奨モデルをGPT-6.1 Solへ変更し、起動ヘッダにバージョンを表示する。help・ログ・エラーは英語へ統一した。
- 無認証または全登録解除済みの対話起動でログイン画面を開く。Subscription認証待ちにはクエリ付きURLを表示し、Ctrl-click・Enter・`o`で開き、`c`で全文をコピーできる。ブラウザが表示されなくても認証待ちは続く。認可待ちはEsc・Ctrl-Cで取り消せる。
- 認証完了・失敗ページはJetBrains Monoを優先し、灰色文字を無彩色に変更した。背景とロゴ・状態マークのアクセント色は保持する。フォント未導入時は等幅フォントへフォールバックする。
- アカウント操作は`/login`・`/logout`・`/status`へ集約する。`/logout`は追加確認なしで対象の認証を解除し、結果を表示する。対象の検証と実行中の拒否は維持する。CLIの`polaris account`は保持する。

### 入力と作業管理

- ログイン画面・ダイアログ・実行中も、可視文字をドラッグして離すと追加確認なしでコピーする。非表示の秘密値は対象外。会話中の実在ファイル名へのCtrl-clickでFinderに所在を表示し、通常クリック・ドラッグでは開かない。
- ファイルのD&Dを入力リンクへ変換し、Backspaceでリンク全体を削除できる。working中のコマンド補完、入力履歴、入力受理ID、子タスクの一覧・停止要求・状態照会を扱える。
- 会話の再開・分岐・作業ファイルを含む巻戻しを提供する。`/session`のprovider変更時の扱い、日本語入力後の背景欠損、readのdirectory一覧、MCP catalog検索の引数処理を修正した。
- workflowの段階・skill・会話履歴を組み合わせてモデル要求を構成する。remember設定は`/memory configure`へ集約し、`/status`は区分と表示幅で整理した。
- TUI・CLIの試験と、status・モデル選択・起動設定・保存台帳検証・envkit配置検査の責務を分離した。操作・公開API・認証と隔離の境界・保存形式は保持する。

### 環境構築と判断器

- CLIの`env plan/set/status`とTUIの`/env`に11種類の固定プロファイルを用意した。計画を確認して専用runtime/cacheでoffline導入・検証を行い、既存manifest/lockfileを保持する。旧`setting nextjs`は削除した。
- Rustでは`POLARIS_ENVKIT_APPLE_TOOLCHAIN=command-line-tools`で既存Command Line Toolsを明示選択できる。global設定とライセンス同意状態は変更しない。
- 型付き判断器の共通factory、明示fallback・local-only、本文を含まない監査・使用量表示を追加した。Clefの通常利用は未提供である。

## 今回提供しないもの

GUI配布、Windows/Linuxの配布・実機保証、Clef/Clef-flashの本番profile、Web検索のcached/live、全MCP serverの接続保証は含めない。APIキー用OpenAI互換経路のAstra tool callingは、ChatGPT認証のCodex経路と同じ対応範囲ではない。

停止要求の成功は外部操作の取消成功を意味しない。保存・適用の結果が不明なときは、表示された照会・復旧操作で状態を確認し、同じ操作を安易に再送しない。

## sourceからの候補作成

Rust 1.96.0、Xcode Command Line Tools、macOS arm64環境を使用する。

```sh
cargo build --locked --offline --release -p polaris-cli
python3 apps/macos/scripts/assemble-cli-pkg.py \
  --binary "$PWD/target/release/polaris" \
  --output /absolute/path/polaris-cli-preview-1.0.0-arm64.pkg
python3 apps/macos/scripts/verify-cli-pkg.py \
  --package /absolute/path/polaris-cli-preview-1.0.0-arm64.pkg \
  --expected-cli "$PWD/target/release/polaris"
```

ソースの構成は[システム構成図](../system-overview.md)、各コマンドは[コマンド参照](../command-reference.md)を参照。
