# Polaris 暫定v1.0.0 — macOS TUI

Polaris暫定v1.0.0は、macOS arm64のTUIを配布対象とする版である。現在は公開準備中であり、タグ・GitHub Release・download URLはまだ公開していない。GUIと他OSのソースは保持するが、今回の配布物には含めない。

## 導入するもの

CLI/TUI実行物だけを含む`polaris-cli-preview-1.0.0-arm64.pkg`を用意する。モデルweights、llama.cpp、Python、Rust、GUI、個人設定・認証情報は含めない。利用者側のRustは不要で、主モデル用の認証またはlocal endpointを別途設定する。

パッケージは未署名・未公証のローカル候補である。Gatekeeperの警告を無視する手順は提供しない。公開用署名や公証を済ませた配布物とは区別する。

2026-10-26に照合した候補は次のとおり。公開download URLはまだない。署名や再生成の後はSHA-256を確定し直す。

| ファイル | 対象 | サイズ | SHA-256 |
| --- | --- | ---: | --- |
| `polaris-cli-preview-1.0.0-arm64.pkg` | macOS arm64 CLI/TUI | 21,974,994 bytes | `44fe7f7178df7ef10d3918e9121934a98d93d214f318db55d3b65a7cdc0d54ac` |

```sh
# 公開後、取得したファイルのSHA-256を配布元の値と照合する
shasum -a 256 polaris-cli-preview-1.0.0-arm64.pkg
# 管理者が導入を承認した場合だけ実行する
sudo installer -pkg polaris-cli-preview-1.0.0-arm64.pkg -target /
polaris --version
polaris login
POLARIS_PROVIDER=codex polaris
```

導入先は`/usr/local/bin/polaris`。異なる既存コマンドやsymlinkを検出するとpreinstallが拒否する。既存ファイルの削除・置換をこの手順で自動化しない。別のPATH上に開発用コマンドがある場合は、`command -v polaris`で起動先を確認する。

## 追加・変更・修正

- TUIの既定・推奨モデルをGPT-6.1 Solへ変更し、起動ヘッダにバージョンを表示する。
- ファイルのD&Dを入力リンクへ変換し、Backspaceでリンク全体を削除できる。会話中の実在ファイル名のクリックからFinderで保存場所を表示し、文章の範囲選択は追加確認なしでコピーする。
- help・ログ・エラーを英語へ統一する。TUIのアカウント操作は`/login`・`/logout`・`/status`へ、remember設定は`/memory configure`へ集約する。CLIの`polaris account`は保持する。
- Rust環境構築では`POLARIS_ENVKIT_APPLE_TOOLCHAIN=command-line-tools`で既存Command Line Toolsを明示選択できる。global設定とライセンス同意状態は変更しない。
- `polaris env plan/set/status`とTUIの`/env`を追加する。11種類の固定プロファイルで、資源の取得計画を確認し、専用runtimeとcacheでoffline導入・検証を行う。既存manifest・lockfileは保持する。旧`setting nextjs`は削除した。

- workflowの段階、skill候補、会話履歴を組み合わせてモデル要求を構成する。
- TUIから会話の再開・分岐、対象入力より前への会話と作業ファイルの巻戻しを行える。
- working中のコマンド補完、子タスクの一覧・停止要求・状態照会を接続した。
- 入力履歴の上下移動、管理コマンドの共通dispatch、`/session`のprovider変更時の扱いを修正した。
- 無認証または全登録解除済みの対話起動で、ログイン専用TUIを開く。既存登録のログイン経路を使い、Esc・Ctrl-Cで登録待機と画面操作を取り消せる。再認証が必要な登録には既存コマンドを案内する。
- `/status`を区分と表示幅で整理し、長いpath・skillを個別行へ分離した。
- 日本語入力後の入力欄背景欠損を修正した。合成PTY確認と実IME確認を区別している。
- readによるdirectory一覧を扱い、MCP catalog検索の引数処理を修正した。
- 型付き判断器の共通factory、明示fallback・local-only、本文を含まない監査と使用量表示を追加した。Clefの通常利用は未提供である。

## 今回提供しないもの

GUI配布、Windows/Linuxの配布・実機保証、Clef/Clef-flashの本番profile、Web検索のcached/live、全MCP serverの接続保証は含めない。APIキー用OpenAI互換経路のAstra tool callingは、ChatGPT認証のCodex経路と同じ対応範囲ではない。

停止要求の成功は外部操作の取消成功を意味しない。保存・適用の結果が不明なときは、表示された照会・復旧操作で状態を確認し、同じ操作を安易に再送しない。

2026-10-26の最終候補は、offline releaseビルド後に実行物を凍結して組み立てた。展開したpayloadは凍結実行物とSHA-256が一致し、隔離したHOME/PATHで`--version`・`--help`・起動先を照合した。実行物はarm64、`polaris 1.0.0`で、SHA-256は`e7823a075a57d09b4f3c56f65e3d920ad5f00b52bf25146c83703b86a4467ffa`。

全workspace試験を実行し、検出した英語化の期待値・旧コマンドの試験などの失敗は、修正後の該当crateと個別再試験で解消した。envkit36試験、共有ownerの境界6試験、全targetのClippy・fmtも成功している。生成された構成図・filemapは現行ソースと照合した。

環境構築は、Node 24.22.1、Next.js 16.4.3、React 19.3.1、Vue 3.5.44、Svelte 5.57.2、Astro 7.4.2、Nuxt 4.6.2、Angular 22.2.3、Python 3.15.1、Go 1.27.3で、固定資源の取得からoffline導入・build・検証・配置・receipt保存まで実行した。最終候補が使う10種類の定義も、成功した実行の定義と一致することを確認した。各実行の証跡はそれぞれの実行物に束縛されており、別実行物へ成功を引き継ぐものではない。RustはCommand Line Toolsの明示選択でcompiler・linker・SDKの検出と計画作成を確認したが、offline実行が隔離で許可されないOpenSSL設定ファイルの読取りを要求し、配置前に失敗した。実受入は未完了である。

最終候補のOS PTYでは、合成会話・status/session/memory・resize後の正常終了を確認した。直前の候補ではログイン画面12ケースの表示・選択・取消・端末設定復元・dummy key非保存を確認している。これはTerminal.appの描画、実IME、VoiceOver、実OAuth・外部モデルの受入を代用しない。pkgの管理者インストール、署名・公証は未実施である。

## sourceからの候補作成

Rust 1.96.0、Xcode Command Line Tools、macOS arm64環境を使用する。

```sh
cargo build --locked --offline --release -p polaris-cli
python3 apps/macos/scripts/assemble-cli-pkg.py \
  --binary "$PWD/target/release/polaris" \
  --output /absolute/path/polaris-cli-preview-1.0.0-arm64.pkg
python3 apps/macos/scripts/verify-cli-pkg.py \
  --package /absolute/path/polaris-cli-preview-1.0.0-arm64.pkg \
  --expected-cli "$PWD/target/release/polaris"
```

ソースの構成は[システム構成図](../system-overview.md)、各コマンドは[コマンド参照](../command-reference.md)を参照。
